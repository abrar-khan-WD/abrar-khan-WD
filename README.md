## 🔥 Featured Projects

### 🤖 [Autonomix — AI Meeting Transcript to Task Dependency Engine](https://assignments-psi-seven.vercel.app)

> Paste a meeting transcript → Gemini AI extracts tasks → dependency graph built → DFS cycle detection runs

**The Problem:** Teams waste hours manually converting meeting notes into actionable tasks with dependencies.

**The Solution:** Paste raw meeting transcript → Google Gemini LLM auto-extracts tasks, assigns priority levels (High/Medium/Low), maps inter-task dependencies, and locks dependent tasks until prerequisites are resolved — exactly like Jira/Linear sprint planning logic.

**Key Technical Highlights:**
- 🧠 **Google Gemini API** for intelligent task extraction and priority classification
- 🔁 **DFS-based cycle detection** — detects circular dependencies before persisting to MongoDB, preventing deadlocks
- 🔒 **Dependency locking engine** — tasks with unresolved dependencies are surfaced as locked; unlocked only when prerequisites complete
- 📊 **Real-time dependency graph** visualization

**Stack:** `React 19` `Vite` `Tailwind CSS` `Node.js` `Express.js` `MongoDB` `Google Gemini API`
